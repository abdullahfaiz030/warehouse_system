# Database Documentation

## Setup Instructions

1. Run `setup_database.php` in your browser
2. All tables will be created automatically
3. Default data will be inserted

## Database Schema

### Tables Structure
- **users** - System authentication and roles
- **locations** - Warehouse/branch locations
- **suppliers** - Vendor management
- **products** - Product catalog
- **stock** - Inventory levels by location
- **movements** - Stock transaction history
- **sales** - Sales transactions
- **sales_items** - Individual sale items
